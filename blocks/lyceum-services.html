Послуги

Підтримка для кожного в ліцеї

Три напрямки роботи — для адміністрації, педагогів і учнів

Для адміністрації

Стратегічні рекомендації щодо психологічного клімату та стабільності колективу

Для педагогів

Профілактика вигорання, групова підтримка та практичні інструменти

Для учнів

Безпечний простір для адаптації, довіри та емоційної стійкості
